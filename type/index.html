about the type

I designed a typeface specifically for animation. Each letter is built on a 3×3 grid, with each cell able to move independently.

The grid gives every piece a place to return to, so the letters can break apart, wander, and snap back together. The logo at the top of each page is a small example of that system in motion.

Below are a few experiments, along with a closer look at how the letters are built.
